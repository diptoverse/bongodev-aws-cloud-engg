# BongoDev AWS Cloud Engineering

Hands-on learning repository documenting practical AWS cloud engineering concepts, assignments, and infrastructure projects from the BongoDev Cloud Engineering course.

## Course Modules

1. **Cloud Fundamentals & EC2**: EC2, SSH, security groups, and Nginx deployment.
2. **IAM, Linux & Nginx**: Identity and access management, Linux administration, and reverse proxy configuration.
3. **Serverless & Databases**: Lambda, DynamoDB, S3, Boto3, and EventBridge.
4. **CloudFormation & Automation**: Infrastructure as Code and GitHub Actions.

## Repository Structure

- `01–04-*`: Course notes and practical assignments.
- `additional-labs/`: Extra hands-on infrastructure labs.
- `cost-management/`: AWS cost checks and resource cleanup documentation.

All exercises focus on practical implementation, secure configurations, and responsible AWS resource management.
